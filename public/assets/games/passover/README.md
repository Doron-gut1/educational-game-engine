# הודעה חשובה - שינוי מיקום קבצי תוכן

## שינוי מקום קובץ data.json 

קובץ ה-`data.json` אשר היה נמצא בתיקייה זו (`/public/assets/games/passover/data.json`) **הועבר** לתיקייה הבאה:

```
/src/games/passover/data.json
```

## סיבות לשינוי

1. **מניעת כפילות** - לא היה צורך להחזיק את אותו קובץ בשני מקומות
2. **מבנה סטנדרטי** - כל קבצי ההגדרות של המשחקים מרוכזים בתיקיית `/src/games`
3. **ניהול תוכן יעיל יותר** - מנוע המשחק מייבא ישירות מתיקיית `/src/games`

## הערה חשובה

שימו לב שכל התכנים בתיקיית `public` צריכים להיות רק נכסים סטטיים כגון:
- תמונות
- קבצי אודיו
- גופנים
- וכו'

ולא קבצי הגדרה או נתונים.

## מה לעשות אם צריך לגשת לקובץ?

```javascript
// במקום לגשת דרך נתיב כמו:
fetch('/assets/games/passover/data.json')

// השתמשו בשירות טעינת התוכן של המערכת:
const content = await ContentLoader.loadGameContent('passover');
```

הקבצים הנמצאים בתיקיית `/src/games/passover/` מומרים אוטומטית ל-bundle בזמן בנייה.
